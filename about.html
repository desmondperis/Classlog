About Class Log

Class Log is a class-coverage and lesson-continuity application built for Mount Carmel School. It helps approved staff record what was planned and taught, continue a topic when another teacher takes a class, coordinate substitutions and review coverage.

What the application does

  • Records planned topics, topics covered and remarks for scheduled classes.
  • Shows department entries to approved colleagues for lesson continuity while restricting who may edit each teacher’s records.
  • Tracks timetables, duties, absences, substitutions and school-diary dates.
  • Provides role-based dashboards and CSV exports for school review.
  • Optionally lets authorised staff ask questions about recent permitted class-log records using Ask AI.

Why Class Log asks for Google access

Google sign-in: Class Log uses a staff member’s name, email, profile image and Google account identifier to verify identity and match the account to a school-approved role.

Google Calendar: Calendar permission is optional and requested separately only when a teacher chooses calendar sync. It is used to create, update or remove Class Log-tagged schedule, duty and substitution events from that user’s primary calendar.

Signing in with Google does not automatically approve an account. An administrator must add the staff email to the selected school branch before application data is available.
